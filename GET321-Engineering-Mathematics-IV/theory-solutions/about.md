# About These Solutions

This document gives worked solutions to the theory questions, Questions 2 to 7, for all five types of the GET 321 paper. Each type starts on a new page and follows the order of the questions on that paper. Several questions appear on more than one type, sometimes under a different number; their solutions are repeated in full so that each type can be read on its own.

## Notes for the Examiner

A few questions contain misprints or wording that admits more than one reading. The solutions handle them as follows.

- **Numerical differentiation table (all types).** The value $f(1.6) = 10.631$ does not fit the rest of the table: the first differences fall steadily from 0.412 to 0.299 and then jump to 0.881. It is most likely a misprint of 10.031, the value in the standard version of this table, which also has $f(1.0) = 7.989$ where the paper has 7.991. The solutions use the five points from 1.1 to 1.5, so the answers do not depend on either value. The figures that students who use the printed $f(1.6)$ would get are also given.
- **Bessel equation (all types).** The fractions $\tfrac12, \tfrac24, \tfrac36, \tfrac48, \tfrac{5}{10}$ are all equal, so every type asks for the same equation, $xy'' + y' + \tfrac12 y = 0$. It reduces to Bessel's equation of order $\nu = 0$. For this order $J_\nu$ and $J_{-\nu}$ are the same function, so the general solution has to use $J_0$ and $Y_0$; the solution explains this.
- **Wave equation (all types).** The paper writes $\delta$ for the partial derivative $\partial$, and "Legendary" for "Legendre". The question boxes here use the standard notation.
- **Damped spring, Type 2, Question 2(b).** The mass is described as both "stretched to 0.7 m" and "released from the equilibrium position". The solution follows the second phrase, $x(0) = 0$ with $x'(0) = 0.6$ m/s, which is the standard form of this problem. The result for $x(0) = 0.2$ m is also given.
- **Power series, Type 2, Question 4(a).** The equation is $2(y'' + 2y) = 0$, whereas the other types use a constant multiple of $y'' + y = 0$. It is solved as printed.
- **Marks.** On Type 3, Question 6(b) carries 7 marks (6 on the other types), and Question 7 shows no marks.
